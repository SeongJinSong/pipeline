# 작업 제목

- Issue: #번호
- PR: 생성 후 자동 연결 (`Closes #번호`)
- 요청: Slack 스레드 링크 / 요청자
- 작성일: YYYY-MM-DD
- 브랜치:

## 문제와 근거

핵심 요구사항·조건 요약과 관찰한 사실 (요청 원문은 Issue에 있으니 붙이지 않습니다). 확인되지 않은 가설은 가설이라고 적습니다.

## 범위와 결정

바꾸는 동작과 이유. 검토했다가 버린 대안과 버린 이유. 범위 밖으로 남긴 것.

## 검증

- 실행한 명령과 결과 (예: `npm run build` 통과)
- 프리뷰에서 확인할 것
- 확인하지 못한 부분
